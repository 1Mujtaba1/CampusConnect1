# 🎓 CampusConnect (CEMS)
### *Campus Event Management System - A Full-Stack MERN Application*

CampusConnect is a robust, centralized platform designed to streamline event coordination within university ecosystems. It replaces fragmented communication methods (like WhatsApp groups and physical posters) with a modern, role-based digital solution.

---

## 🚀 Key Features

### 👤 For Students
- **Real-time Discovery:** Browse upcoming departmental fests, workshops, and seminars.
- **One-Click Registration:** Secure your spot instantly with automatic seat tracking.
- **Personal Profile:** View and manage all your registered event tickets in one place.
- **Advanced Filtering:** Search events by category (Tech, Cultural, Sports) or timeframe.

### 🏛️ For Department Organizers
- **Event Proposal:** Submit comprehensive event details including posters, venues, and descriptions.
- **Management Dashboard:** Track registration counts and manage event lifecycle.

### 🛡️ For Administrators (HOD/Authority)
- **Role-Based Approval:** Review and approve/reject event proposals to maintain campus standards.
- **User Feedback:** Dedicated portal to view and respond to student inquiries via the Contact system.

---

## 🛠️ Technical Stack

- **Frontend:** React.js, Tailwind CSS, Framer Motion (Animations), Lucide Icons.
- **Backend:** Node.js, Express.js.
- **Database:** MongoDB (NoSQL) with Mongoose ODM.
- **Authentication:** JWT (JSON Web Tokens) & Bcrypt password hashing.
- **Styling:** Glassmorphism UI Design.
